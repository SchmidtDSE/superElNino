# Super El Nino across scales

This project aim to analysis how the Super El Nino event of 1982 appears across climate data sets of various scales, resolutions,  and origin in the Mojave Desert od the Desert Southwest

The datasets we want to look at are
Historical/ Reanalysis
- PRISM
- ERA5
- ERA5-Land
- Pierce et al. (https://journals.ametsoc.org/view/journals/hydr/22/7/JHM-D-20-0212.1.xml)

Historical runs from climate models
- CMIP6
- ISIMIP
- CalAdapt (LOCA2-Hybrid)


Historical datasets should reproduce exact event. Climate models cannot expected to do so, but should produce statistically similar events.
