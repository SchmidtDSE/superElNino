### Main

This file sketches out the rules of this project.**It should only be changed by a human!**

- `README.md` is for human->human only. This is the entry point for any human who seeks to understand what this project is about. `README.md` has authority over all other documentation when in doubt. *AI is **not** allowed to edit this file!*
- `claude.md` is for AI->AI. This is intended as  Claude's sketchpad and serves to document Claude's work for itself.
- `log.md` is for AI->human. Claude should document it work here in a succinct, parsimonous way for a human scientist seeking to understand what Claude's process. It is Claude's responsibility to keep this document up to date while working, and also to make sure it is human friendly, avoids jargon or overly verbose lanuage.  
- `instructions.md` gives instructions to Claude. AI can edit when explicitly allowed to do so. If AI thinks it needs to edit this file, it should check in and wait for explicit approval.
